# Reference robot bust

Open [nova-reference-robot-bust.blend](nova-reference-robot-bust.blend) in Blender. Its active scene is **NOVA / Reference Robot Bust**. Numpad `0` shows the saved portrait camera.

- [GLB model](../characters/nova-reference-robot-bust.glb): 3.53 MB, self-contained, Y-up, meters.
- [Front portrait](../previews/nova-reference-robot-bust.png): 1200×1400 transparent PNG.
- [Back view](../previews/nova-reference-robot-bust-back.png): 800×1000 transparent PNG.
- [Validation report](../previews/nova-reference-robot-bust-validation.json).

The editable upper-body model includes separate head, concentric ear modules, antennae, modeled facial features, neck, torso panels, shoulders, and forearms. Rear service-panel details complete the 3D interpretation of the supplied portrait.

The model measures 1.2544 m wide, 0.6756 m deep, and 1.7696 m tall. Its origin is the assembly origin; its lowest point is approximately Z = -0.132 m in Blender. It has 110 meshes, 16 materials, and 165,908 evaluated triangles. It is a static review master, with geometry and PBR materials ready for further editing. The iris shading is carried by portable vertex colors. No image textures or external models are required.

The GLB was structurally checked and reimported successfully in an independent Blender scene. Studio lights and cameras are excluded from the export. The Blender source retains the portrait camera and lighting.

Creation: Blender 5.3.0 and local Python modeling, based on the user-provided reference. Open the delivered Blender file for edits. The three build/refine/finish scripts are retained as production sources; regeneration should use a fresh scene and a new output stem to preserve this deliverable.
